Under arbetet med Postgres Zoo-projektet arbetade jag med backend-delen av applikationen med hjälp av Java Spring Boot
och PostgreSQL-databasen. Min uppgift var att arbeta med Puma-entiteten, där jag implementerade ett servicelager som
tillåter att skapa, visa, uppdatera och ta bort data. Jag använde också en validator för att säkerställa att
informationen är korrekt innan den sparas i databasen.

Jag implementerade loggning med Logback och SLF4J för att registrera viktiga operationer och eventuella fel. Genom detta
lärde jag mig hur viktig loggning är för att övervaka applikationens drift och lättare hitta problem.

Under projektet använde jag Git och GitHub för att arbeta med kodversioner, inklusive att forka repositoriet, arbeta på
min egen gren och skicka in ändringar. Jag använde också Docker för att köra applikationen, vilket hjälpte mig att
bättre förstå hur en applikation kan köras i en isolerad miljö.

Det här projektet hjälpte mig att få en bättre förståelse för Spring Boot-applikationer, att arbeta med databaser,
loggning, Git och Docker, samt att få mer självförtroende i att arbeta med backend-utveckling.
